# Sofusa Tap

## How do I install these formulae?

`brew install sofusa/tap/<formula>`

Or `brew tap sofusa/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sofusa/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
